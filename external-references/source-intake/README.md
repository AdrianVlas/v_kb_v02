# Source Intake

This directory is reserved for controlled external source intake.

No source artifact is treated as knowledge-base content until its identity, provenance, revision basis, applicability, and authority status are recorded.

## Required intake metadata

- source identifier
- source type
- origin or repository
- exact revision, date, or version when available
- supplied-by information when established
- intended MA consumer
- authority status
- integrity or hash information when fixed
- unresolved questions and restrictions

## Intake rules

- do not invent source owners, revisions, timestamps, or hashes;
- do not copy source content without preserving its origin;
- do not promote an external reference to normative knowledge implicitly;
- keep source evidence separate from derived knowledge;
- record missing information as NOT_ESTABLISHED.
